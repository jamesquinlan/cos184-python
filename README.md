# COS 184 - Introduction to Python Programming

Welcome to the Introduction to Python Programming course repository! This course is designed to teach fundamental programming concepts using Python, one of the most popular and versatile programming languages today.

## 📚 Course Overview

This course covers the essentials of programming with Python, including:
- Variables, data types, and operators
- Control structures (conditionals and loops)
- Functions and modular programming
- Data structures (lists, tuples, dictionaries, sets)
- File I/O operations
- Object-oriented programming basics
- Error handling and debugging
- Working with libraries and modules

## 🚀 Getting Started

### Prerequisites

- Python 3.8 or higher installed on your system
- A text editor or IDE (recommended: VS Code, PyCharm, or Jupyter Notebook)
- Basic computer literacy

### Installation

1. Clone this repository:
   ```bash
   git clone https://github.com/jamesquinlan/cos184-python.git
   cd cos184-python
   ```

2. Verify Python installation:
   ```bash
   python --version
   # or
   python3 --version
   ```

3. (Optional) Create a virtual environment:
   ```bash
   python -m venv venv
   source venv/bin/activate  # On Windows: venv\Scripts\activate
   ```
