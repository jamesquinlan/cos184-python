# COS 184 - Introduction to Python Programming
## Course Syllabus

### Course Information

**Course Title:** Introduction to Python Programming  
**Course Code:** COS 184  
**Instructor:** James Quinlan  
**Credits:** 3  

### Course Description

This course provides a comprehensive introduction to programming using Python. Students will learn fundamental programming concepts including variables, data types, control structures, functions, and object-oriented programming. The course emphasizes hands-on learning through lab exercises and practical projects.

### Course Objectives

By the end of this course, students will be able to:

1. Write, debug, and test Python programs
2. Use variables, data types, and operators effectively
3. Implement control structures including conditionals and loops
4. Create and use functions for modular programming
5. Work with common data structures (lists, tuples, dictionaries, sets)
6. Read from and write to files
7. Apply basic object-oriented programming concepts
8. Handle errors and exceptions appropriately
9. Use Python libraries and modules
10. Solve problems using algorithmic thinking

### Course Topics

#### Week 1-2: Python Basics
- Introduction to Python and programming
- Variables and data types
- Basic input/output
- Operators and expressions

#### Week 3-4: Control Structures
- Conditional statements (if, elif, else)
- Boolean logic
- Loops (while, for)
- Break, continue, and pass statements

#### Week 5-6: Functions and Modules
- Defining and calling functions
- Parameters and return values
- Scope and lifetime of variables
- Modules and imports
- Standard library overview

#### Week 7-8: Data Structures
- Lists and list operations
- Tuples
- Dictionaries
- Sets
- List comprehensions

#### Week 9-10: File I/O and String Manipulation
- Reading and writing files
- Working with CSV and JSON
- String methods and formatting
- Regular expressions (introduction)

#### Week 11-12: Object-Oriented Programming
- Classes and objects
- Attributes and methods
- Inheritance
- Encapsulation basics

#### Week 13-14: Advanced Topics
- Error handling and exceptions
- Debugging techniques
- Working with external libraries
- Introduction to popular libraries (e.g., requests, pandas)

#### Week 15: Review and Final Project
- Course review
- Final project presentations
