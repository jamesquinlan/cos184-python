# Source Code Examples

This directory contains example Python programs demonstrating various programming concepts covered in COS 184.

## Examples Overview

### Basic Concepts
- **01_hello_world.py** - Your first Python program
- **02_variables_datatypes.py** - Working with variables and different data types
- **03_arithmetic_operations.py** - Mathematical operations in Python
- **04_string_operations.py** - String manipulation and methods
- **05_input_output.py** - Getting user input and formatting output

## Running the Examples

To run any example:

```bash
python filename.py
```

or

```bash
python3 filename.py
```

For example:
```bash
python 01_hello_world.py
```

## Interactive Examples

Some examples (like `05_input_output.py`) require user input. When you run these, the program will prompt you to enter information.

## Learning Tips

1. **Read the code** - Each file has comments explaining what the code does
2. **Run the examples** - See the output for yourself
3. **Modify the code** - Try changing values and see what happens
4. **Experiment** - Use these as starting points for your own programs

## Code Style

These examples follow Python best practices:
- Clear variable names
- Comments explaining the code
- Proper formatting and indentation
- Use of f-strings for formatting (Python 3.6+)
