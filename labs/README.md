# Labs Directory

This directory contains all lab assignments for COS 184 - Introduction to Python Programming.

## Lab Organization

Each lab is contained in its own markdown file with complete instructions, requirements, and submission guidelines.

## Available Labs

- **[Lab 1: Introduction to Python and Basic Operations](lab1.md)**
  - Hello World program
  - Basic arithmetic
  - Variables and data types
  - User input
  - String manipulation
  - Circle calculations

## Working on Labs

1. Read the lab instructions carefully
2. Create a working directory for your lab solutions
3. Complete each exercise as specified
4. Test your code thoroughly
5. Submit according to the instructions provided

## Submission Format

Each lab specifies its submission requirements. Generally:
- Create a folder named `labX_yourname` (where X is the lab number)
- Include all required Python files
- Ensure all programs run without errors
- Follow the naming conventions specified

## Getting Help

If you need assistance:
- Review the course documentation in `../docs/`
- Check example code in `../src/`
- Consult the Python documentation
- Attend office hours
- Ask questions during class

## Tips for Success

- Start early - don't wait until the deadline
- Test your code incrementally
- Use meaningful variable names
- Add comments to explain your logic
- Follow Python style conventions (PEP 8)
- Save your work frequently
